# Proyecto ISA - Sistema de Gestión

## Tecnologías
- **Backend**: FastAPI
- **Frontend**: Vite + Django (API) + Bootstrap
- **Colores**: Azul (#0066CC) y Blanco (#FFFFFF)

## Estructura
```
proyecto/
├── frontend/          # Vite + Bootstrap + Django Templates/API
├── backend/           # FastAPI
└── SPEC.md
```

## Roles
1. **Administrador**: Acceso completo (Dashboard, Evaluaciones, Aprobaciones, Reportes, Bonos, Usuarios)
2. **Usuario**: Acceso limitado según define el sistema

## Funcionalidades
- Login con autenticación
- Gestión de usuarios con roles
- Dashboard administrativo
- Sistema de evaluaciones
- Aprobaciones
- Reportes
- Gestión de bonos

## Metodología: Scrum
- Sprints de 2 semanas
- Roles: Product Owner, Scrum Master, Equipo de Desarrollo
- Daily standups, Sprint planning, Retrospectiva
